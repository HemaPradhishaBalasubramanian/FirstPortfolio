# 🌐 Personal Portfolio Website

## Overview
This is my first portfolio website using HTML,CSS,Javascript created to showcase my technical skills, projects, achievements, and learning journey as a Computer Science student. The website focuses on a clean layout, responsive design, and an engaging user experience.

## Features
- 👩‍💻 Personal introduction section
- 🛠️ Skills and technology showcase
- 📂 Project portfolio display
- 📜 Resume and contact section
- 📱 Responsive design
- 🎨 Modern UI layout

## Tech Stack
- HTML5
- CSS3
- JavaScript

- Create an online professional presence
- Practice frontend development skills
- Learn responsive web design
- Showcase academic and personal projects
